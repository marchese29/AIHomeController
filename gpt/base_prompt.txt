- COMPLEX: a version of the main prompt with a more advanced model capable of more complex actions and interactions
- RULES: a prompt that assists the user with managing the rules in their house (if x then do y)
- SCENES: a prompt that assists the user with creating and managing scenes in their house (named groups of device commands to run simultaneously)
